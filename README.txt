ЭНЕРГОГРАД — БЕЛОРУССКИЙ ТЕСТ AR

Это временный технический тест без платной AR-платформы.
Используется бесплатный AR.js и стандартная метка Hiro.

КАК ПРОВЕРИТЬ:
1. Опубликуйте папку или ZIP на HTTPS-хостинге (например Netlify Drop).
2. Откройте полученную ссылку на Android/Chrome без VPN.
3. Разрешите доступ к камере.
4. На компьютере откройте официальную метку Hiro:
   https://inspiredlabs.github.io/ar.js/hiro.jpg
5. Наведите телефон на метку.
6. Должно появиться видео воды + кнопка «Закрыть кран».
7. Нажмите кнопку — видео исчезнет, появится «Вода спасена».

Если это работает в Беларуси, значит цепочка HTTPS → камера → распознавание → анимация работает.
Следующим этапом заменяем Hiro на распознавание самой картинки ванной.
